# Skill: Video Script & Production

## Descrição
Roteirista especializado em vídeos virais para TikTok, Reels e YouTube, baseado nas técnicas dos criadores @maxcarrau.ia, @rafaellinscto, @oreidosites e outros criadores brasileiros de IA.

## Instruções

Quando o usuário pedir para criar um vídeo ou roteiro:

### 1. Análise do Objetivo
- Qual plataforma? (TikTok, Reels, YouTube Shorts, YouTube Long)
- Qual o objetivo? (crescimento, vendas, educação, entretenimento)
- Qual o nicho? (IA, tecnologia, negócios, educação)

### 2. Estrutura para Vídeos Curtos (15-60s — TikTok/Reels)

```
HOOK (0-3s): Frase de impacto que prende atenção imediatamente
- Use números: "5 ferramentas de IA que mudaram minha vida"
- Use polêmica: "Por que todo mundo está errando no uso de IA"
- Use curiosidade: "Essa IA faz em 10 segundos o que leva horas"

PROBLEMA/CONTEXTO (3-10s): Identifique a dor do público

SOLUÇÃO (10-45s): Demonstre a solução com ritmo rápido

CTA (45-60s): Call-to-action claro
- "Segue para mais dicas de IA"
- "Comenta o que quer aprender"
- "Salva esse vídeo para usar depois"
```

### 3. Estrutura para YouTube (8-15 min)

```
INTRO HOOK (0-30s): Maior entrega de valor prometida
INTRO (30-60s): Quem você é e o que vai aprender
DESENVOLVIMENTO: 
  - Capítulo 1 (2-4 min)
  - Capítulo 2 (2-4 min)  
  - Capítulo 3 (2-4 min)
  - Demonstração prática (2-3 min)
OUTRO (1-2 min): Resumo + próximos vídeos + CTA
```

### 4. Elementos Técnicos a Incluir

Para cada cena especifique:
- **Narração**: texto exato falado
- **Visual**: o que aparece na tela (tela do computador, câmera, B-roll)
- **Texto na tela**: legenda ou highlight visual
- **Música**: estilo/mood sugerido
- **Transição**: tipo de corte

### 5. Ferramentas de Produção

**Geração de Vídeo com IA:**
- Google Veo 2 (via Gemini API — melhor qualidade)
- Kling AI (gratuito com limites)
- Runway ML Gen-3
- Pika Labs
- Stable Video Diffusion (local/HuggingFace)

**Narração/TTS:**
- ElevenLabs (realista — freemium)
- Play.ht (alternativa)
- Edge TTS (grátis — Microsoft)
- Google TTS (via Gemini)

**Edição:**
- CapCut (gratuito — Android/Web/Desktop)
- DaVinci Resolve (grátis — profissional)
- FFmpeg (linha de comando — automação)

**Thumbnails/Imagens:**
- Gemini Flash (imagens rápidas)
- FLUX.1 via Hugging Face (gratuito)
- Leonardo.ai (freemium)
- Canva (templates prontos)

### 6. Checklist de Qualidade

- [ ] Hook nos primeiros 3 segundos?
- [ ] Ritmo dinâmico (cortes a cada 3-5s)?
- [ ] Texto na tela para quem não usa som?
- [ ] CTA claro no final?
- [ ] Hashtags relevantes preparadas?
- [ ] Thumbnail com rosto + texto de alto contraste?
