# Pesquisa técnica

## Procedimento

1. Defina a pergunta objetiva (o que precisa ser decidido).
2. Colete de fontes primárias: documentação oficial, repositório no GitHub, changelog.
3. Registre **URL + data de acesso** para cada afirmação relevante.
4. Compare no mínimo duas opções quando houver escolha: licença, custo, manutenção, requisitos.
5. Entregue tabela curta + recomendação única + o que ainda falta confirmar.

## Regras

- Nunca cite modelo, endpoint ou versão que você não viu na fonte.
- Se a informação for sensível ao tempo (preços, limites gratuitos), diga a data da consulta.
- Separe claramente "documentado" de "inferido".
